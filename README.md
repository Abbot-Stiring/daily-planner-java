# Daily Planner (Java)

A simple Java-based daily planner application to track income, expenses, and workouts.

## 📌 Features
- Add job income
- Add expenses
- Log workouts
- View all saved data

## 🛠️ Technologies Used
- Java
- File Handling (FileWriter, Scanner)

## ▶️ How to Run

1. Compile the program:
   javac DailyPlanner.java

2. Run the program:
   java DailyPlanner

## 📁 Data Storage
- jobs.txt → stores income
- expenses.txt → stores expenses
- workouts.txt → stores workouts

## 🎯 Purpose
This project was built to practice Java basics such as:
- Input handling
- File handling
- Program structure
